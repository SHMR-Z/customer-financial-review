# 虚构客户财报试跑：Aurora

本文件是示例答案，所有数据和情节虚构。来源为同目录synthetic-statements.md，2024/2025完整年度单体管理报表，无独立审计报告，原单位为千BRL。结论不能用于真实客户。

**现有资料不足以支持延长无担保账期。** 收入增长，但主营盈利转负、现金更依赖供应商账期，且没有客户实际回款记录和债务到期表。可先完成补件核验，再结合现有敞口讨论调整；不能仅凭财报批准具体额度。

2025年的净利润30由营业亏损10、其他净收益70、净财务支出20及所得税10组成（§2）。其他收益的性质未解释，不能确认可持续性，也不能直接称为一次性收入。

经营现金流80中，应付供应商增加180是重要支撑，库存增加150则占用现金（§5）。这可能反映供应商账期、规模变化或付款压力；需要应付账龄和合同资料确认，不能仅凭应付增加断言拖欠。

资产负债、毛利、现金变动、期末现金及留存收益均算术勾稽通过：2025年现金100+80−100+40+0=120；留存收益80+30−10+0=100（§3/§4）。这只说明随包虚构数字一致，不证明原件真实性、审计合格或实时支付能力。

延长账期前，应优先取得最近月度管理报表、其他收益明细、债务到期/续贷情况、应付账龄、现金限制资料，以及我方现有应收、逾期和拟增敞口。客户行业基准、评级制度和交易信息缺失，暂不给固定信用等级、违约概率或具体额度。
