# 分析口径与判断

## 材料及期间

财报所述主体与交易法人必须核对。集团合并报表不是子公司的独立偿债证据；关联方支持需确认限制。登记审计报告是否提供、意见类型和关键事项；工商登记/签章不等于独立审计。

比较数优先当前报表明确重述后的上期数，记录重述原因。季度/YTD与全年不直接算同比；期末余额和期间流量分开。周转天数使用匹配期间的平均余额及适合流量，期末余额替代平均数只能另标估算。

## 数值和缺项

保留原文，例如`1.234,56`；确认葡语格式后转1234.56。格式不明确的`1.234`不可直接判断为1.234或1234。括号通常为负数但需核原表；短横线可能为零、空白或不适用。不同单位逐项统一，不用展示值回算。

输入脚本的费用、成本、CAPEX、股利为正数；净现金流、利润及调整保留正负。原报表成本负号须解释标准化，不重复扣减。已披露为零保留0；未知用null。

## 指标定义（脚本口径）

| 指标 | 口径及限制 |
|---|---|
| 毛利率/净利率/营业利润率 | 毛利/净利润/披露营业利润 ÷ 净营业收入；收入>0，不把营业利润自动叫EBIT |
| 收入/净利润同比 | 本期/上期−1；仅同主体、范围、币种、期间长度；上期≤0不按常规百分比解释，可叙述亏损扩大/收窄/扭亏 |
| 流动比率 | 流动资产÷流动负债；关注资产可变现性、寄存材料货权 |
| 速动比率 | （流动资产−存货−预付款−其他非速动资产）÷流动负债；四项需有证据，未知扣除项不默认为0 |
| 现金覆盖短债比率 | 已确认的不受限现金÷流动负债；不是覆盖有息借款的比率 |
| 营运资金 | 流动资产−流动负债 |
| 资产负债率 | 总负债÷总资产；资产>0 |
| 负债/权益 | 总负债÷权益；权益≤0不输出误导性杠杆倍数 |
| 净债务 | 已明确口径的有息债务−不受限现金；说明租赁/股东借款是否包含；净现金仍可伴随贸易债务压力 |
| 经营现金流/净利润 | 净利润>0才计算现金转化率 |
| 自由现金流（分析口径） | 经营现金流−现金支付CAPEX；固定资产净增额不等于CAPEX，也不是唯一FCF定义 |

这些是本skill分析定义，非准则强制规定。脚本不计算DSO、ROE、利息覆盖或EBITDA倍数；需要时取得进一步资料并注明口径。

## 勾稽

- 资产−负债−权益；收入−销售成本−毛利。汇总不含已计入合计的子项。
- 期初现金+经营净流量+投资净流量+融资净流量+汇率及其他已披露调整−期末现金。透支/现金范围差异需解释；现金流期末与资产负债表现金另核。
- 留存收益：期初+同权益主体利润−股利+其他已披露净调整−期末。不得把未解释差额反填调整；合并归母/NCI不能混用。
- 容差由输入提供，使用原报表单位。不能为通过检查放大容差；算术通过不代表财报可信。

## 发现与客户管理建议

| 发现 | 需要验证 | 可以讨论的客户动作 |
|---|---|---|
| 净利润正、营业利润负 | 其他收益/汇兑/处置收益性质及持续性 | 延长账期前取得近期经营及实际回款证据 |
| 经营现金流正、应付款大增 | 拖延付款/供应链融资/正常规模扩张 | 补应付账龄及资金计划，讨论节点回款 |
| 应收/库存占用增加 | 账龄、减值、货权、订单覆盖 | 核现有逾期及新增赊销回收周期 |
| 短债集中或资本侵蚀 | 续贷、契约、股东支持、抵押限制 | 暂缓提高无担保敞口，讨论保证金/担保/分批放货 |
| 资料不全或审计有保留 | 保留影响及最近资料 | 补证据，不把缺资料直接写成违约 |

避免行业外统一阈值评级；正式额度需交易规模、敞口、逾期、账期及内部审批制度。

## 准则核验入口

只在适用准则问题中使用，按报表实际期间与采用版本核查；不复制标准全文。

- [IFRS Foundation：IAS 7](https://www.ifrs.org/issued-standards/list-of-standards/ias-7-statement-of-cash-flows/)：现金流分类及现金勾稽入口，不是本skill比率或信用判断的来源。
- [IFRS Foundation：IAS 1 supporting material](https://www.ifrs.org/supporting-implementation/supporting-materials-by-ifrs-standards/ias-1/)：比较数与持续经营资料入口；注意后续准则替代及实际采用情况。
