# Excel输出模板

默认输出Excel：复制`assets/customer-financial-template.xlsx`到工作输出目录，使用副本填写，不覆盖随包空白资产。若用户提供模板，以用户模板为准。

公开模板沿用既有“报表情况、业务分析、提示事项”三页和主要栏目，清除了客户数字、叙述、固定汇率及失效区域；修复了断链、自引用、单位转换和缺数据时产生零值的问题。它是清理修复版，不是原文件的逐字副本。

## 填写顺序

1. 在“提示事项”登记客户、原币代码、主体范围、审计及读取情况。B5填写一个输入单位对应的基础货币数：千元1000、百万元1000000、亿元100000000。模板默认亿元，先核对并修改。全表原币输入统一单位。
2. “报表情况”B44:E44填各实际期间；两期材料填D列上期、E列本期。核验比较范围/币种/期间长度/重述后，才把“提示事项”B9设为“是”。所有参与比较的期间都须确认；不可比用“否”。
3. 仅填有来源的蓝字输入。未披露留空，真实零填0；叙述及“提示事项”来源区写明缺项。B:E为原币；H:K是美元公式区，使用相同金额倍率。
4. 需要美元展示时填B6原币/美元汇率及B7日期与来源；否则保留空白，美元区不会显示假零。单一汇率仅适用于用户明确指定的展示口径，不自动将其当各年适用会计折算汇率。
5. 上方综述填写已核事实、解释及待验证事项。“业务分析”填写业务/客户结构、经营驱动、资金需求、关联方、回款风险及敞口建议。按用户问题填写，缺交易信息不批具体额度。
6. 复核“提示事项”差额，按B16记录的实际容差解释；核对原报表披露值，不能倒填调整配平。B16是人工复核记录，不控制其他输出，也不强制生成评级。
7. 重算后检查公式错误、空白与零、百分比/百分点、单位、换汇及三页视觉效果，再交付Excel；Markdown或计算JSON可作为补充。

顶部净利润使用第107行披露值，而非自动采用第93行测算值；EBITDA使用第109行，不从营业利润擅自估算。模板无法完整表达特殊利润表时，调整科目标签和公式并留来源，不硬塞平衡。

第57:65行换算百万原币，用输入金额×B5/1000000。第71行为百万原币营运资金，第73行为相邻可比期间变化。这些行保留原模板的隐藏状态，可取消隐藏55:77行查看。上方金额表保持原币输入单位；比例变化显示百分比或百分点。

留存收益、受限现金、净债务及详细比率可用skill计算器和相关附注另核，并按任务补到原有栏目/提示事项，不强行用当前模板空缺项代替。
